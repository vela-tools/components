# @vela-tools/ngsi

The NGSI-LD model, runtime and bound components of Vela Components: the provider, hooks and commands, the bound roots that fill the `@vela-tools/ui` families from a broker, and composites such as `EntityBrowser` and `SubscriptionManager`. `@vela-tools/ngsi/query` builds and parses NGSI-LD queries, and `@vela-tools/ngsi/testing` provides a mock adapter.

```bash
npm install @vela-tools/ngsi @vela-tools/ui @mantine/core @mantine/hooks @tanstack/react-query react react-dom
```

Give the provider adapters from `@vela-tools/ngsi-client`, or your own implementation of its adapter interfaces.
