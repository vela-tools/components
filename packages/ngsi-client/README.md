# @vela-tools/ngsi-client

The NGSI-LD client of Vela Components: `createNgsiLdAdapter` implements the adapter interfaces of `@vela-tools/ngsi` over the NGSI-LD API, for entities, types, temporal data, subscriptions and saved queries. It has no React dependency.

```bash
npm install @vela-tools/ngsi-client @vela-tools/ngsi
```

The broker must allow the application's origin in its CORS settings.
