# @vela-tools/ui

The components, theme and app shell of Vela Components: primitive families of parts, leaves, and the design tokens. It knows nothing about brokers; `@vela-tools/ngsi` binds its components to NGSI-LD data.

```bash
npm install @vela-tools/ui @mantine/core @mantine/hooks react react-dom
```

Import `@vela-tools/ui/styles.css` once, next to Mantine's styles. Import `@vela-tools/ui/fonts` once as well to load the Geist fonts the theme uses; without it the theme falls back to the system fonts.
